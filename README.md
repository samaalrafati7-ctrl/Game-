# Cyber Detective — IEEE CS JUST

A simple, browser-based mystery game for university event booths.

## Run
Open `index.html` in a modern browser. No installation, API key, or backend is required.

## Publish as a website
1. Upload all files in this folder to a GitHub repository.
2. Sign in to Vercel using GitHub.
3. Import the repository as a new project.
4. Choose **Other** as the framework preset.
5. Leave the build command empty and use `.` as the output directory.
6. Deploy.

## Notes
- The leaderboard is saved in the current browser using localStorage. It is not shared between different laptops.
- The three cases and their clues can be edited in `script.js`.
- Colors and layout can be changed in `style.css`.
